六选五 · 圆桌版原型

同一套几何，三端切换。头像与名字沿椭圆环排布，中央毡面承载公共信息，牌盘下移为「你面前的托盘」。

当前设计空间

  • 2~5 人（含自己），不再做 6/8 人档
  • 准备界面长在牌桌上：同一个坠面、同一个座位环，不另开房间页
  • 退出、局终再来一局都在同一条操作栏上，不换页面
  • 一局结算 3~5 次：每比完一组立刻结算，见底者当场出局
  • 点别人头像 → 贴着他弹出面板（表情 / 短语 / 个人信息，同一张卡切）
  • 点自己头像 → 同一张卡，直接落在个人信息；操作栏气泡 → 贴自己开表情
  • 给自己发＝就地出现；给别人发＝从我头像到他头像旁的一条直线
  • 四种特写：王十点半 / 豹子 / 牛牛 / 五花牛，只有赢家放
准备态与对局态共用同一张牌桌：中间是房号与就绪计数，下方是「准备 / 开始 / 退出」

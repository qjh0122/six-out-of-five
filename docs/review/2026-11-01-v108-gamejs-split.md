### 总手法：只搬定义，不动调用点

每个模块导出 `create(deps)`，内部把注入项解构成**与 `game.js` 里完全同名**的局部变量。
于是主文件里几千处调用点一个字都不用改。

反过来做（把 `state` 挂到命名空间、调用点全改成 `LXW.state.xxx`）要改几千处，
漏一处是**运行时炸**而不是编译期报错 —— 那种改动没人敢做第二次。

**验证**：把 HEAD 版 `game.js` 的 334 个函数体与新代码逐一对账 —— **丢失 0 个**，
所有差异都是机械改写（`onHandCardTap` → `deps.onHandCardTap`、`slotTypeSeen = x` → `CardView.setSlotTypeSeen(x)`）。

## 拆分过程中挖出的 5 处静默失效

这是本轮最值得记的部分。**它们全都不报错、不动 UI 结构、4463 条断言全绿**，
表现形式统一是「点了没反应」。

| # | 缺陷 | 后果 | 怎么发现的 |
|---|---|---|---|
| 1 | `modalKit.js` 的**导出块整块丢失**，`api` 成了空对象 | 建房 / 账号 / 规则 / 战绩……**所有弹窗全哑** | 浏览器探针：`TypeError: showModalEl is not a function` |
| 2 | `cardView.js` 定义了 8 个尺寸常量却**没导出** | 牌面视觉正常，但主文件的**布局计算全变 `NaN`**（扇形排布、飞牌落点、组槽上界） | 新守卫第 3 组（`NS.key` 反查） |
| 3 | 9 个依赖**按值传引用**，而它们的 `var` 赋值在创建点之后（`var` 不提升值） | `settleView` 的弹窗/滚动渐隐/有没有机器人、`accountView` 的弹窗与 `recordsPid` 永久是 `undefined` | 新守卫第 4 组（越序检查） |
| 4 | `settleView` 用了裸 `BIG_TYPES`，但它住在 `cardView` 里、没注入 | 结算页 `render()` 抛异常 → **第 2 轮起界面不再重绘** | 新守卫第 5 组（自由标识符）+ 浏览器复现 |
| 5 | `settleView` / `seatSheetView` / `recordsView` 用了裸 **`state`**，三个模块都没注入 | 同上：房间到第 2 轮就不重绘，看起来像「点提交永远没反应」 | 运行时栈：`ReferenceError: state is not defined` |

### 为什么这些 bug 特别难查

`js/roomStore.js:537` 把订阅回调包在 `try { cb(room) } catch (e) {}` 里 ——
**异常被静默吞掉**，连控制台都不进。所以现象是「界面卡住、零报错、零日志」。

后来是靠给回调临时套一层 `try/catch` 抓栈才看见的：
`ReferenceError: state is not defined at settleView.js:273`。

4463 条旧断言全绿却漏掉一个致命 bug，说明**守卫站错了层级**：

| 3 | **`game.js` 里每个 `NS.key` 读到的名字，模块里真的有** | ✔ 删 `api.MODAL_ORDER` → 红 |

## 关键取舍

| 决定 | 为什么 |
|---|---|
| **`recordsView` 的创建点挪到 modalKit 解构之后**，不在它原来的位置 | 它要用 `showModalEl` / `isShown`，那些是 `var`（不提升值）。在原位置创建拿到 `undefined`，后果是**弹窗开关静默失效**（不报错，就是点了没反应）。代码里留了四行注释说明后果 |
| **`historyKit ↔ recordsView` 的循环依赖用 getter 打破** | 前者要 `recordsPid`（在后者里），后者要 `packHistory`（在前者里）。直接传值会在创建那一刻固化 `undefined` |
| **9 个函数依赖包一层透传**，而不是重排创建顺序 | 重排要挪动 250 行装配代码，风险大于收益；包装是局部改动，且新守卫第 4 组会盯着 |
| **`api.x = function` 全部改回 `function x()` 声明** | 仓库里几十条源码守卫用的是 `/function (\w+)\(/`。改模块写法比改断言安全 —— 断言代表设计意图 |
| **28 个测试文件改成读多份源码**（`test/helpers/gameSource.js`） | 另一条路是删/放宽断言，那等于拿测试换结构 |
